# ☕ MAMETO COFFEE — ホームページ & オンライン注文システム

自家焙煎コーヒー店向けの、かっこいいホームページ＋ネット注文の仕組み一式です。
**追加インストール不要**（Node.js の標準機能だけで動きます）。

![hero](shots/01-hero.png)

## できること

- 🎨 **おしゃれなブランドサイト** — ヒーロー / こだわり / メニュー / 店舗情報
- 🛒 **オンライン注文** — カートに入れて、お名前と受取時間を入れるだけ
- 📋 **店舗スタッフ用の管理画面** (`/admin.html`) — 入った注文をリアルタイム表示、
  「準備開始 → 受取可 → 受渡完了」のステータス管理、本日の売上集計
- 📱 スマホ対応（レスポンシブ）
- 💾 注文は `data/orders.json` に自動保存

## 使い方

```bash
cd coffee-shop
node server.js
```

ブラウザで開く:

| ページ | URL |
| --- | --- |
| お店のサイト（お客さま用） | http://localhost:3000/ |
| 注文管理（スタッフ用） | http://localhost:3000/admin.html |

ポートを変えたいとき: `PORT=8080 node server.js`

## メニューの編集

`data/menu.json` を書き換えるだけ。店名・住所・営業時間・商品・価格すべてここで管理します。
サーバーを再起動すると反映されます。

```jsonc
{
  "shop": { "name": "MAMETO COFFEE", "address": "...", "hours": "...", ... },
  "categories": [
    { "id": "espresso", "name": "エスプレッソ",
      "items": [ { "id": "latte", "name": "カフェラテ", "price": 520, "badge": "人気", ... } ] }
  ]
}
```

## 仕組み（ファイル構成）

```
coffee-shop/
├── server.js          依存ゼロの API + 静的配信サーバー
├── data/
│   ├── menu.json      メニュー・店舗情報（ここを編集）
│   └── orders.json    注文の保存先（自動生成）
└── public/
    ├── index.html     お客さま向けサイト
    ├── admin.html     スタッフ向け管理画面
    ├── css/           デザイン
    └── js/            カート / 注文 / 管理ロジック
```

### API

| メソッド | パス | 説明 |
| --- | --- | --- |
| `GET`   | `/api/menu`        | メニュー取得 |
| `POST`  | `/api/orders`      | 注文作成 |
| `GET`   | `/api/orders`      | 注文一覧（管理用） |
| `PATCH` | `/api/orders/:id`  | ステータス更新 `{ "status": "preparing" }` |

## お支払いについて

現状は **店頭でのお支払い**（受け取り時）を前提にしています。
オンライン決済（Stripe / PayPay 等）を入れたい場合は `submitOrder` と `POST /api/orders` の間に
決済処理を足す形で拡張できます。ご希望があれば対応します。

## 注意

- `data/orders.json` は実際の注文データなので Git には含めていません（`.gitignore` 済み）。
- 本番運用するなら、HTTPS 化・管理画面のパスワード保護・データベース化を推奨します。
```

> このままでも社内・店頭のタブレットでの受注に十分使えます。
> 本番公開（独自ドメイン・常時起動）まで進めたい場合は声をかけてください。
```
