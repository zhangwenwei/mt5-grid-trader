# GridTrader 策略探索总结(EURUSD 为主,真实 Tick 回测)

> 全程 MT5 真实Tick(Model 8)回测,非手算模拟。约 100+ 次回测。
> 绝对 JPY 数值受"区间宽度 / FirstAtEdge / 是否跨窗持仓"影响偏乐观,**重点看相对排名与方向性结论**。
> 所有"赚钱"结论的前提:**行情是区间盘**。

## 一、最终推荐配置(双向 + 开 LossCut + 阶梯手数)
| 参数 | 值 | 说明 |
|---|---|---|
| 方向 | 双向(Buy+Sell) | 任何行情净利都最高(见§三) |
| GridCount | 28(格距随区间宽自适应) | 净利-密度曲线顶点、盈利因子最高 |
| TpThreshold_BasePips | 30–45 | 甜区,平台稳健 |
| LotForLine_InitLots / Reduce | 0.02 / 0.01(阶梯) | 增益;保守可用固定 0.01 |
| **LossCut_MinOrders** | **8(开)** | **单项最有价值,净利↑、回撤↓** |
| 区间 Upper/Lower | 罩住近期实际价幅(宽静态) | 别滚动收窄、别比价幅宽 |
| 移动止损/趋势过滤 | 关 | 无效或有害 |

> 可直接加载的参数文件见 [presets/GridTrader_best.set](../presets/GridTrader_best.set)(用前必把 Upper/Lower 改成当前近3月实际高/低)。

## 二、各实验结果
### 1) 参数寻优(纯震荡窗 2023.07–2024.12,FAE=true)
- 最优:格28/TP45/阶梯0.03↓0.01 → 净利 +6787、回撤 1.3%、PF 4.88、RF 5.04、零爆仓。
- 相关性:净利对格数=凹形(峰 24–32);对 TP=内部最优(甜区 30–45);对手数=线性放大但回撤/PF 同步恶化;回撤几乎只由手数推动。

### 2) 走查:静态 vs 滚动区间(2024,FAE=false)
| | 合计净利 | 备注 |
|---|---|---|
| 静态(宽带固定全年) | +18,044 / +38,140(最佳配置) | 赢 |
| 月度滚动 | +11,370 | 输 |
| 季度滚动(最佳配置) | +10,636 | 输 |
- **滚动一律输给静态**:重设成更窄的近期带后,一遇下季漂移就被穿出、频繁越界止损。**罩住全程的宽静态区间最好。**

### 3) 方向变体(只多/只空,纯参数)
| 行情 | 双向 | 只多 | 只空 |
|---|---|---|---|
| 2023H1 涨 | **59948** | 38839 | 21109 |
| 2024 净跌 | **31110** | 6749 | 24361 |
- 单方向=赌宏观方向(涨段只多赢、跌段只空赢),**但都打不过双向**(双向同时吃漂移+两侧震荡,LossCut 砍逆势失血)。

### 4) 参数级策略对照(2024 全年)
| 策略 | 净利 | 回撤 | PF |
|---|---|---|---|
| 基线 | 18044 | 27.7% | 1.17 |
| 移动止损 | 23083 | 26.7% | 1.22 |
| **超单保护 LossCut=8** | 26180 | **21.8%** | 1.25 |
| 阶梯手数 0.02/0.01 | 22974 | 28.9% | 1.21 |
| **阶梯 + 超单保护** | **31110** | 23.3% | **1.30** |

### 5) 换品种泛化(2024,最佳配置)
| 品种 | 净利 | 回撤 | PF |
|---|---|---|---|
| EURUSD- | +38174 | 16.8% | 1.44 |
| EURGBP- | +14101 | 14.6% | 1.22 |
| EURCHF- | +9514 | 29.9% | 1.07 |
| EURCAD- | +15935 | 18.5% | 1.13 |
- 四个 EUR 交叉盘**全部正收益、零爆仓** → 配置可泛化(EURUSD 最强、EURCHF 最弱)。

### 6) 代码变体:趋势暂停(分支 strat/trend-pause,负面)
- 最敏感档仅略降回撤、净利不增;放松阈值转亏。**趋势/指标过滤对网格无效**,与历史 ADX 结论一致。不建议并 main。

### 7) 多品种严格样本外 walk-forward(IS=2024H1 定区间 → OOS=2024H2,最佳配置)
| 品种 | IS 净利(上半年) | OOS 净利(下半年) |
|---|---|---|
| EURUSD- | +57,057(DD8.8%) | **−3,315**(DD15.1%) |
| EURGBP- | +29,752(DD10.9%) | **−8,188**(DD13.3%) |
- **样本内大赚 → 样本外转亏**:H2 价格漂出了用 H1 定的区间,固定区间一遇漂移就失效;但 OOS 仍**零爆仓、回撤压在 13–15%**。
- **结论**:风控泛化、收益不泛化。**别拿样本内数字外推**;实盘按"风控可信、收益看行情"预期,区间要勤对齐当前价幅。

## 三、核心结论
1. **EA 自带、默认关着的「超单亏损保护 LossCut」是最有价值的开关**(净利↑、回撤↓),本分支把默认改为 8。
2. **双向 + LossCut + 阶梯手数 + 宽静态区间 + 只在区间盘** = 最优组合,且跨品种泛化。
3. **加代码/加过滤/滚动区间/赌方向都没能超过它**。网格成败 90% 看「行情匹配(区间 vs 趋势)+ 区间放对」,不是调参或加指标。
4. 全部配置零爆仓——越界全平兜底有效。

## 四、风险与免责
- **样本内 ≠ 样本外**:多品种 walk-forward 显示样本内大赚、样本外转亏(见 §二.7);绝对数值多为 FAE=false 放大,别外推。
- 阶梯手数是双刃剑(放错区间会放大亏损,曾 −35k 爆仓);只在区间放对时用。
- 一切以"区间盘"为前提;趋势段会亏(已验证),实盘前须判断当前行情类型。
